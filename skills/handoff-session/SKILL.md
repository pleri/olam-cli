# Handoff session

Full state transfer via a GitHub draft PR. The receiver gets the exact state — code, agent context, environment — and continues seamlessly with `/olam:pickup-session` (when that skill ships).

---

## Prerequisites

- `gh` CLI installed and authenticated (`gh auth status` returns OK).
- CWD is inside a git repository with a `origin` remote on GitHub.

---

## Workflow

### 1. Anchor to repo

```bash
ROOT=$(git rev-parse --show-toplevel)
REPO=$(git remote get-url origin | sed 's|.*github.com[:/]||;s|\.git$||')
BRANCH=$(git branch --show-current)
```

### 2. Commit uncommitted work

1. `git status` — check for uncommitted changes.
2. **Pre-stage secret scan** (mandatory before `git add`). Run:
   ```bash
   git status --porcelain | awk '{print $2}' | grep -E '\.(env|key|pem|p12|pfx|jks)$|credentials|secrets|\.aws/|\.ssh/' || true
   ```
   If ANY match surfaces: STOP. List the matches to the operator. Tell them to either (a) `git rm --cached <file>` if already tracked, (b) add to `.gitignore` and remove from the working tree, or (c) confirm explicitly that the file is safe to ship in a draft handoff (rare — operator must say so verbatim). Do NOT proceed with `git add -A` until secrets are excluded.
3. If dirty and the secret scan is clear:
   - Stage all changes: `git add -A` (handoff captures the full working tree; receiver gets a draft PR and can prune before merge).
   - Create the WIP commit:
     ```
     wip: handoff — <one-line description of current state>
     ```
4. If clean, skip.

### 3. Push branch

1. If on `main` / `master`, create a feature branch first: `handoff/<target-or-name>-<YYYY-MM-DD>` (e.g. `handoff/sam-2026-05-14`).
2. `git push -u origin "$BRANCH"`.

### 4. Upload transcript as gist

1. Find the current session's transcript:
   - Scan `~/.claude/projects/*/` for `.jsonl` files.
   - Match by current session id.
2. Upload as a **secret** gist (the `--secret` flag is required — `gh gist create` defaults to public, which would index the transcript in GitHub gist search):
   ```bash
   gh gist create --secret --desc "Session transcript — handoff from <user> $(date -u +%Y-%m-%dT%H:%M:%SZ)" <transcript-path>
   ```
3. Capture the gist URL from output.

### 5. Detect olam world (if applicable)

If CWD is inside `~/.olam/worlds/<world-id>/`, extract the world id + repos + branch so the receiver can recreate it:

```bash
WORLD_ID=$(echo "$ROOT" | sed -n 's|.*/.olam/worlds/\([^/]*\)/.*|\1|p')
```

If a world id is detected, include the recreate snippet (see "Environment setup" below). Otherwise skip the env-setup block.

### 6. Create the draft PR

1. Extract from the session transcript:
   - **Goal** — what was being worked on
   - **What's done** — completed work
   - **What's next** — remaining tasks
   - **Environment setup** — bash commands the receiver needs (olam world recreation if detected, or plain dev-server boot otherwise)
   - **Files touched** — key files modified
   - **Other repos** — if the session touched repos other than the CWD repo

2. Check if a PR already exists for this branch:
   ```bash
   gh pr view --repo "$REPO" --json number 2>/dev/null
   ```
   - Exists → update with `gh pr edit`.
   - Not yet → create new draft.

3. PR body shape:

   ```markdown
   ## Handoff from <user> — <YYYY-MM-DD>

   ### Goal
   {what was being worked on}

   ### What's done
   - {completed items}

   ### What's next
   - [ ] {remaining tasks}

   ### Environment setup
   ```
   {setup commands — see snippet below if olam world}
   ```

   ### Files touched
   - {key files}

   ### Session transcript
   [Full transcript](<gist-url>) — load with `/olam:pickup-session`.

   ---
   Generated by `/olam:handoff-session`.
   ```

4. Create as draft:
   ```bash
   gh pr create --repo "$REPO" --draft \
     --title "handoff: <brief goal>" \
     --body "$(cat <<'EOF'
     ...
     EOF
     )"
   ```

### 7. Report

Output the PR URL and a 1–2 sentence summary of what was handed off.

## Environment setup — olam world recreation

When the session ran inside an olam world (`~/.olam/worlds/<id>/`), include:

```bash
# Recreate the olam world
olam create <world-id-or-new-name>

# Re-attach the same repos (if multi-repo)
olam repo add <repo-1> <repo-2>

# Dispatch the in-flight task to the recreated world
olam dispatch <world-id> "<task-description>"

# Or: open an interactive shell into the world
olam enter <world-id>
```

If the session ran on the host directly (not inside an olam world), include a plain dev-server boot snippet appropriate to the repo's stack instead (e.g. `bundle install && bin/dev`, `npm install && npm run dev`, etc.).

---

## Multi-repo sessions

If the session touched repos other than the CWD repo, handoff targets the **CWD repo's branch**. Other repos are mentioned in "What's next"; their state is NOT auto-transferred — the receiver must pull each affected repo separately. Document the list explicitly in the PR body.

---

## Rules

### ALWAYS
- Create a WIP commit when there are uncommitted changes.
- Push the branch BEFORE creating the PR.
- Upload the full transcript as a gist (do not paste raw transcript content into the PR body).
- Use `--draft` for handoff PRs — handoffs are never ready-to-merge.
- Include the environment setup block (olam world recreate, or stack-appropriate dev-server boot).
- Pass `--repo "$REPO"` explicitly on every `gh` invocation.
- Return the PR URL when done.

### NEVER
- Push to `main` / `master` — always use a feature branch.
- Put raw transcript content in the PR body — gist only.
- Skip the transcript upload.
- Create a non-draft handoff PR.
- Use this skill for a polished, ready-to-merge handoff — that's a regular PR via `/olam:commit-push-pr`.

---

## Failure handling

- **`gh` not authenticated** — surface `gh auth status` output and ask the user to run `gh auth login`.
- **No remote `origin`** — refuse; ask the user to add a GitHub remote first.
- **Transcript file not found** — proceed without the gist; note "transcript not located" in the PR body's "Session transcript" section. The receiver picks up without the full agent context.
- **Gist upload fails** (rate limit / network) — surface the error; retry once; if still failing, proceed without the gist and note it in the PR body.
- **Public gist accidentally created** (e.g. `--secret` flag forgotten by future edit; operator-overridden command) — IMMEDIATELY tell the operator to run `gh gist delete <id>` and rotate any credentials that appeared in transcript output (Bash tool outputs, error messages, API responses). Public gists are indexed by GitHub gist search + crawled by external indexers; the only safe assumption is the content was scraped.
- **Pre-stage secret scan refused** — operator must clean up the working tree before re-invoking. Common fixes: `git rm --cached <file>`, add to `.gitignore`, or move the file outside the repo root.
- **Existing PR on the branch is not a draft** — ask the user whether to push handoff content into the existing PR or start a fresh branch.
- **Detected olam world id does not exist in `olam list`** — include the recreate snippet anyway; the receiver may have a different `~/.olam/` profile.

---

## Anti-scope (what this skill is NOT for)

- **Polished, ready-to-merge PRs** — use `/olam:commit-push-pr` instead.
- **Pickup on the receiver side** — that's `/olam:pickup-session` (planned; not yet shipped). Until then, the receiver checks out the branch + opens the gist transcript manually.
- **Long-term documentation of the work** — handoff PRs are ephemeral context; canonical docs live elsewhere.
- **Multi-repo state transfer** — only the CWD repo's branch is transferred; other repos must be handed over separately.
